저장소 연결

토큰 만드는 법
  1. GitHub 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access에서 Only select repositories를 고르고 이 사이트 저장소 하나만 선택
  3. Permissions → Repository permissions → Contents를 Read and write로 (Metadata는 자동으로 Read-only)
  4. 만료 기간을 정하고 Generate token을 누른 뒤, github_pat_로 시작하는 값을 위 칸에 붙여넣기

토큰은 GitHub API에만 보내고, "저장"을 체크했을 때만 이 브라우저(localStorage)에 남습니다. 공용 컴퓨터에서는 체크하지 마세요.

GitHub Desktop 등으로 클론한 저장소 폴더(그 안에 assets/js/data.js가 있는 폴더)를 고르면 파일을 직접 고칩니다. 커밋과 푸시는 평소처럼 직접 하세요. Chrome과 Edge에서만 됩니다.
